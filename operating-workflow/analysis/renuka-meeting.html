Confidentiality model — "Hermes the role, scoped access"
A wall is a scoping boundary on one role, not a blindfold. The two real risks are narrower than "Hermes sees data":
① Cross-wall co-mingling (Client A bleeding into Client B)
② Cloud exfiltration (confidential data leaving local)

Solved by: local Hermes plane reads raw confidential data in wall-scoped ephemeral sessions (dropped on wall-switch). Cloud Hermes plane coordinates across walls on redacted abstractions + metadata only. Raw data never hits the cloud.

Hermes always carries its model of Sai across all walls — that is the chief-of-staff value and is not client data.

Identity & Calibration — The Counterweight Layer
Two-stream fusion method
Stream A (top-down):
Raw psychometric data read directly — not summarized — from: Clifton StrengthsFinder, SDI, iEQ9 Enneagram, Big Five. Extract the unflattering structural findings.
Stream B (bottom-up):
One behavioral observation logged per session. Failures + validated good calls. Captures real events (e.g. a paid-API mistake → instantly a permanent rule).
Fusion = operating manual. Every rule has three parts:
Rule Why (the finding) Trigger + action
Then: durability test — prove it loads in a fresh session, or it decays into an unloaded file.
Critical note
Architecture copies; contents do not. Using someone else's operating manual calibrates the AI to their gaps, not yours. The method is copyable; the calibration data must come from Sai's own assessments + behavioral log.
