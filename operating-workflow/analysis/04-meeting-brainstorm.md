## A) "Here's what I absorbed from your system" (lead with this — it earns the room)

Say it crisply. It proves mastery and respect in 90 seconds:

1. **The thesis:** memory tools remember *conversations*; the second brain is where
   my *work and knowledge physically live*. Two layers, both kept.
2. **Walls:** separate vaults per context, hard-isolated; sync handled by Obsidian,
   not the agent; privacy = files stay local.
3. **Identical taxonomy + the bridge index** — the agent reads the bridge first and
   never scans the vault. *"The repetition is the feature."*
4. **Five-layer file memory** + `MEMORY.md` index loaded every session.
5. **The daily rhythm** anchored on `FOCUS.md`; **`session-end` is the keystone** —
   skip it and the system decays.
6. **Session skills (~5) vs library skills**; you orchestrate, the agent follows.
7. **The calibration layer:** the operating manual *fused* from raw psychometrics +
   a behavioral log; every rule = rule + why + trigger; verified to actually load.
8. **Continuous learning:** corrections compound into permanent rules, validated
   wins saved too so it doesn't drift timid.

> One line to her: *"Your real contribution isn't the folders — it's that the
> structure means the agent never guesses, and the calibration means it pushes
> back. That's what I'm taking."*

## B) "Here's where I'm building it differently" (shows independent thinking)

1. **Integrated core + walls** — you run personal as a *peer silo*. I'm making
   **personal/professional the integrating *core*** that client/company walls plug
   into. I integrate my *life*; I wall my *clients and companies*.
2. **Hermes as chief of staff** — a coordinating layer above the vault you don't
   have yet. A **role, not one process**: a local plane reads confidential data, a
   cloud plane coordinates on redacted metadata.
3. **Scoped-confidentiality model** — Hermes orchestrates on *metadata*, wall
   agents read *contents*; no cross-wall co-mingling, no cloud exfiltration.
4. **GTD for the agentic age** — vertical (altitude) preserved but every node gets
   an *owner* + *autonomy level*; horizontal CPORD **distributed across actors**
   and extended with **Delegate + Verify**.
5. **Calibration as a shared spine** — the operating manual propagates to *every*
   agent, not just one; eventually **per-domain** calibration.
6. **A layered architecture** (Identity · Direction · Operating Model · Knowledge ·
   Workflows · Tech + Governance spine) so it scales and productizes.

## C) Brainstorm topics & questions (60-min agenda)

### C1 — Mine her proven layers (highest-value PROBES)
- **The maintenance/decay reality:** "What *actually* happens the weeks you skip
  `session-end`? What decays fastest?" ← the single most valuable answer.
- **Which ~5 skills do you run daily** vs built-and-abandoned?
- **Calibration:** time-to-payoff? upkeep cost? has it ever **mis-fired**, and how
  did you fix it? Start it now or after the basics run?
- **Taxonomy:** what did you add then **prune**? Does the **bridge index still keep
  context lean** once a wall gets big?
- **Cron:** automated anything yet — did it help or break?
- **Feedback memory:** over months, how do you avoid **bloat/contradiction**? Ever
  **retire** a stale rule?

### C2 — Pressure-test my divergences (where she may spot holes)
- **Integration vs walls:** "I'm integrating personal+professional into one core.
  You went the other way. What breaks when contexts share a space — what did you
  see bleed?"
- **Scoped confidentiality:** "Hermes coordinates on metadata, wall agents read
  contents. Do you see a hole in that?"

### C3 — Co-design as peers (the Hermes/agent half — neither has cracked it)
- **The three translation moves** (file access · load rules every session · saved
  workflows): where does she expect Hermes to fight back?
- **Multi-agent supervision** — "one agent raises another": real yet, or still
  aspirational? What's the blocker?
- If she were wiring Hermes tomorrow, **where would she start?**

### C4 — Relationship / forward
- **Offer to be her Hermes-integration test case** — I'm ahead on that exact build.
- Ask her to send: a **redacted real skill + her `MEMORY.md` + `CLAUDE.md`**.
